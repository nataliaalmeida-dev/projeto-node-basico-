Este projeto foi desenvolvido como atividade prática do curso de Testes de Software, com o objetivo de demonstrar conhecimentos básicos de Node.js e utilização de um repositório remoto.

Estrutura do projeto

O projeto possui a seguinte estrutura:

projeto-node-basico/
├── src/
│   └── index.js
├── package.json
└── README.md
O que foi desenvolvido

Neste projeto foram apresentados alguns conceitos básicos de JavaScript utilizando o Node.js:

Criação e utilização de variáveis;
Criação e utilização de funções;
Exibição de informações no console;
Realização de uma operação de soma;
Configuração básica de um projeto Node.js através do arquivo package.json.
Variáveis

Foram utilizadas variáveis para armazenar informações como nome, idade e curso.

Exemplo:

const nome = "Natalya";
let idade = 38;
const curso = "Testes de Software";
Funções

Também foram criadas funções para demonstrar a organização e reutilização de código.

Exemplo:

function somar(numero1, numero2) {
    return numero1 + numero2;
}
Como executar

Para executar o projeto, é necessário ter o Node.js instalado.

No terminal, dentro da pasta do projeto, execute:

npm start

O programa exibirá os resultados diretamente no terminal.

Objetivo

A atividade tem como objetivo praticar a criação de uma estrutura básica de projeto Node.js e compreender conceitos fundamentais de programação que serão utilizados durante o curso de Testes de Software.
